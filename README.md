# Bolets Bages

App web personal para buscar setas en el Bages. Calcula en el móvil la probabilidad de encontrar rovelló, llenega negra, fredolic o camagroc para cada cuadrito de unos 30 m. Usa:

- la meteo de Meteocat en directo y la previsión de Open-Meteo;
- el relieve de Copernicus DEM;
- el bosque visto por satélite (ESA WorldCover, 10 m);
- los caminos de OpenStreetMap.

Es una estimación, no una garantía. Respeta la normativa, las fincas privadas y las batidas de caza.
